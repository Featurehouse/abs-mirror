Title: Auto Pack Script

Date: Fri 27 Jun 2025 00:55

Input: 1) Minecraft version, such as `1.21.6`, `1.21.7-rc2`. 2) The output folder.

According to server.jar output (in `generated/reports/items.json`):
```
java -DbundlerMainClass=net.minecraft.data.Main -jar server.jar --reports
```
Get a CSV document, for example:
```
#alphabet,id,han_num,chinese_name
A,apple,2,苹果
B,bamboo,2,竹子
```
from which unfetchable items will be manually removed.

Then, use another script to generate the data pack from the modified CSV document.
In the data pack, we only need to generate the following JSON files:

a) For SpeedABC
For each file, IDs under the exact alphabet will be included.
In `data/speedabc/tags/items/{alphabet}.json`:
```
{"replace": false, "values": ["id1", "id2", "id3", ..., "idN"]}
```

b) For HanNumSpeed
For each file, IDs whose corresponding Chinese (zh_cn) translate has the exact count of characters (codepoint count).
In `data/hannumspeed/tags/items/len_{han_num}.json`:
```
{"replace": false, "values": ["id1", "id2", "id3", ..., "idN"]}
```

Reference URLs:
- Minecraft version manifest: `https://piston-meta.mojang.com/mc/game/version_manifest_v2.json`
- Version meta (1.21.6.json): `https://piston-meta.mojang.com/v1/packages/72747754e421b04db4816145639f8ca9c467c0a8/1.21.6.json`
- Asset Index for 1.21.6: `https://piston-meta.mojang.com/v1/packages/4aa210b13ee1168cae6655f66808a5fbc39a6168/26.json`
where we only need to find `minecraft/lang/zh_cn.json`. In this case, its hash is `6a829093df0c8f7d3942e26655290334925a9b23`, so head to:
- Chinese (zh_cn) translations: `https://resources.download.minecraft.net/6a/6a829093df0c8f7d3942e26655290334925a9b23` (JSON file)

What we need to consider here is:
1) The ID itself. For example, `minecraft:acacia_button` is a valid ID. IDs are expected to start with `minecraft:`. They should be trimmed to something like `acacia_button`.
2) Value of `minecraft:item_name`, such as `block.minecraft.acacia_button`. This is the key in `zh_cn.json`.
